# Discord-бот NE S27

Бот связывает Discord и сайт через одноразовый код. Пароль пользователя не
передаётся боту, не хранится в Discord и не отображается администраторам.

## Что умеет

- команда /connect отправляет одноразовый код и ссылку в личные сообщения (с приватным ответом на сервере, если ЛС закрыты);
- /profile показывает токены, осколки, тайники и приглашения;
- /collection показывает найденные карточки;
- /invite создаёт личное приглашение и запоминает его владельца;
- бот автоматически фиксирует нового участника и выдаёт награду после проверки;
- синхронизирует ник, отображаемое имя и аватар;
- /s27-admin tokens и /s27-admin verify — защищённые админ-команды;
- копирует новые сообщения только из разрешённых новостных каналов на сайт.

## Запуск

1. Создайте Discord Application и Bot в Developer Portal.
2. Включите привилегированные intents Server Members Intent и Message Content Intent.
3. Дайте боту права View Channels, Create Instant Invite и Use Application Commands.
4. Скопируйте файл .env.example в .env и заполните значения.
5. Установите зависимости командой npm install.
6. Зарегистрируйте команды: npm run register.
7. Запустите: npm start.

Значение BOT_WEBHOOK_SECRET должно быть одинаковым у бота и в секретах сайта.
ADMIN_ROLE_IDS содержит Discord role ID через запятую. На стороне сайта
дополнительно задаётся ADMIN_DISCORD_IDS: даже украденная роль не даст доступ
к серверным административным операциям без разрешённого Discord ID.

Бота можно разместить на любом Node.js-хостинге с постоянным процессом. Токен
бота нельзя добавлять в Git, отправлять в сообщения или хранить в коде.
